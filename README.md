# KVANTOY APP — алгачкы PWA версиясы

Бул — `app.kvantoy.site` үчүн мобилдик биринчи интерфейстин баштапкы долбоору.

## Азыр иштеген бөлүктөр
- Башкы бет: учурдагы KVANTOY API'ден макалаларды жүктөйт.
- Макаланы окуу: `title` — аталыш, `caption` — толук текст.
- Билдирүүлөр: API'деги `created` убактысы боюнча акыркы 72 сааттагы макалаларды көрсөтөт.
- AI: `https://ai.kvantoy.site/` дарегине коопсуз жаңы өтмөк ачат.
- Орнотуулар: караңгы/жарык режимди түзмөктө сактайт.
- PWA manifest жана Service Worker shell cache.

## Маалымат булагы
`https://kvantoy.kg07nurislam.workers.dev/api/posts`

Учурдагы API'ге өзгөртүү киргизилбейт. Макалалар браузерден түз окулат.

## Жайгаштыруу
1. ZIP архивди ачып, ичиндеги файлдарды жаңы GitHub репозиторийине жүктөңүз.
2. Репозиторийдин Settings → Pages бөлүмүнөн `Deploy from a branch` тандаңыз.
3. Branch катары `main`, folder катары `/ (root)` тандаңыз.
4. GitHub Pages даяр болгондо Custom domain бөлүмүнө `app.kvantoy.site` жазыңыз.
5. DNS башкаруусунда `app` үчүн GitHub Pages берген CNAME жазуусун кошуңуз.
6. HTTPS күйгөнүн текшериңиз.

## Маанилүү чектөөлөр
- Бул версияда сервердик push-билдирүүлөр жок. Билдирүүлөр тиркеме ачылганда жана ачык турганда ар 5 мүнөт сайын текшерилет.
- API учурда сүрөт URL талаасын кайтарбайт, ошондуктан биринчи версияда макала сүрөттөрү көрсөтүлбөйт.
- AI өзүнчө доменде ачылат; iframe аркылуу ичине камтылган эмес.
- Service Worker учурда колдонмонун shell файлдарын кэштейт. Толук offline макала режими кийинки этапта кошулат.
- Интерфейс алгачкы прототип; өндүрүшкө чыгаруунун алдында Android/iOS браузерлеринде тестирлөө зарыл.
